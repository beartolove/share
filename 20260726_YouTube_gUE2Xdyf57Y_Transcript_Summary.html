行政通 TaskFlow 建置使用說明

一句話總結

作者分享了一款利用 Google Apps Script 和 AI 技術打造的公文進度整理工具，方便教師管理公文期限與內容，並提供詳細部署與使用教學。

#YouTube逐字稿#科技及AI新知#AI工具

重點摘要

  1. 利用 Google Apps Script (GAS) 串接 AI，實現公文內容自動摘錄與期限整理。
  2. 工具前台為獨立 HTML，結合 Google CVAS 服務，免申請 API key 即可使用 AI 功能。
  3. 提供完整部署流程，包含建立 Google 試算表副本、部署 GAS、下載並修改 HTML、上傳至 CVAS 等步驟。
  4. 支援批次上傳最多五份公文，自動分析並列出公文號、標題、發文字號、處理期限等資訊。
  5. 可設定到期預警，並能快速複製本機資料夾路徑，方便快速找到公文檔案。

關鍵觀察

  • 工具可在無 AI 功能環境下使用，僅做文字整理，但無法自動摘錄重點。
  • 由於瀏覽器安全限制，無法直接從網頁點擊開啟本機資料夾，需手動複製路徑貼上檔案總管。

適合使用情境／可延伸思考

  1. 教師或行政人員需管理大量公文，追蹤處理期限與內容摘要。
  2. 需要簡易且免繁複申請 API key 的 AI 應用部署方案。
  3. 可延伸整合其他行政檔案管理系統，提升工作效率。

對熊熊導入 AI 工具的啟發

透過結合 Google 雲端服務與 AI，能打造免繁瑣設定、易於部署且具實用性的行政工具，降低使用門檻並提升工作效率。

限制與提醒

  • 瀏覽器安全限制導致無法直接點擊開啟本機資料夾，需手動操作。
  • 批次上傳限制最多五份公文，若檔案量大需調整程式碼。
  • 若不使用 CVAS，AI 功能將無法啟用，僅能做基本文字整理。

結論

此公文進度整理工具結合 AI 摘錄與 Google 雲端技術，提供教師及行政人員一個方便管理公文的解決方案，並附上詳細部署教學，降低使用門檻，提升行政效率，是一款實用且具啟發性的工具。
