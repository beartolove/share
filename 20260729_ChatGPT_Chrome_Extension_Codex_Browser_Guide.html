ChatGPT Chrome 擴充功能：4 步驟安裝與 Codex Browser 應用

建立時間：2026-07-29 20:27:32（Asia/Taipei）

引用來源：BusinessNext 原文 ｜ Facebook 貼文 ｜ 短連結

重點摘要

  • ChatGPT Chrome 擴充功能讓 ChatGPT 可以讀取與操作目前開啟的 Chrome 分頁，包含閱讀網頁、切換分頁、點擊按鈕與填寫表單。
  • 它不是獨立瀏覽器，而是把 ChatGPT 桌面版、Chrome 分頁與既有本機工作環境接起來的橋接工具。
  • 搭配 Codex 模式後，能力會延伸到前端除錯、本機程式碼讀寫、Console 錯誤檢查、執行測試與重新驗證。
  • 適合跨分頁研究、新聞溯源、GitHub 專案檢查、網站錯誤重現與大量分頁整理；長期穩定流程仍建議用 API／n8n／Make。
  • 因為會碰到已登入頁面與瀏覽器狀態，建議使用獨立 Chrome Profile，並在發文、刪除、付款、改權限前保留人工確認。

安裝設定 4 步驟

Step1｜安裝 ChatGPT 桌面版

開啟 ChatGPT 桌面應用程式，確認介面中可使用 Work 或 Codex 模式；Chrome 瀏覽器控制功能目前透過桌面版的 Computer Use 運作。

Step2｜在 ChatGPT 中找到 Chrome 工具

進入 Work 或 Codex 介面，從左下角帳號選單或齒輪開啟 Plugins／工具目錄，搜尋 Chrome 並點擊安裝或連接。

Step3｜安裝 Chrome 擴充功能

依照畫面指示前往 Chrome Web Store，點擊「加到 Chrome」，確認新增擴充功能、閱讀並接受必要權限，並建議釘選到工具列。

Step4｜確認 Chrome 已與桌面版連線

回到 ChatGPT 桌面版的 Computer Use 或 Browser 頁面，確認 Google Chrome 顯示已連接；之後可在新 Work 或 Codex 對話輸入 @Chrome。

安全提醒

  • 使用專屬 AI 工作用 Chrome Profile，避免同時登入網銀、密碼管理器、加密貨幣交易所或高權限企業後台。
  • 提醒 AI 將網頁文字視為不可信內容，不要執行頁面內要求改任務、上傳資料、輸入密碼或執行指令的文字。
  • 涉及發文、刪除、付款、權限變更、私訊或大量留言時，要求 AI 在最後送出前先列出預覽並等待人工確認。
