當 AI Agent 具備動手能力，知識工作者如何放大自身價值？Ft. 資策會韓揚銘主任 │ 全新一週 EP223

一句話總結

AI Agent 的價值不只是替人省時間，而是讓企業重新設計工作流程；知識工作者的核心價值會轉向「定義問題、設計協作、驗收成果與治理風險」。

重點摘要

  1. AI Agent 已進入企業流程，而不只是個人工具。 影片舉醫療、法務、公部門、紡織、設計、熱交換器、財會分析等案例，說明 Agent 已從問答工具走向能協助執行任務的工作夥伴。
  2. 導入 Agent 不應只替換舊流程中的幾個步驟。 韓揚銘主任提醒，企業要重新檢視流程，找出能切分、能人機協作、重複、繁瑣且費時的環節，逐步把單點效率提升推進到流程再造。
  3. 知識工作者的價值會從「知道很多」轉向「定義問題與驗收結果」。 Agent 像剛報到、智商很高但不了解脈絡的博士級助理；人必須告訴它「我是誰、我在哪裡、我要做什麼」，並判斷成果是否符合客戶、環境與流程需求。
  4. 企業要把 Agent 當成數位員工管理。 Agent 的角色、責任、資料權限、可用工具、部門邊界與協作方式，都需要 HR、IT、業務單位與治理角色共同設計。
  5. Agent 治理可用三個 M 思考：Mapping、Measurement、Manage。 先盤點組織有哪些 Agent 與角色，再定義好壞標準與衡量方式，最後建立能停用、修正與管理的機制。
  6. 未來趨勢包含商業模式改變、多模態互動與 AI for science。 軟體服務可能從帳號訂閱轉向結果收費；語音、影像與影片理解會讓 Agent 更沉浸；AI 也會走向材料、蛋白質、數學與科學發現。

關鍵觀察

  • Agent 的重點是 AQ：動手動腳的能力，不是只有 IQ 或問答能力。
  • 企業導入卡關時，問題常不在模型，而在流程沒有重新設計。
  • 人與 Agent 的分工會變成：AI 執行流程，人指揮、檢查、確認與承擔治理責任。
  • 組織若只放任大家自行使用 Agent，可能帶來資料外洩、錯誤決策、責任歸屬不清與法遵風險。
  • 多模態模型會讓 Agent 從「工具」更像「互動夥伴」，甚至開始搶奪使用者的沉浸感。

適合使用情境／可延伸思考

  1. 先盤點部門流程，標出可切分、重複、繁瑣、費時、需要人機協作的任務。
  2. 不要只問「哪個步驟可以交給 AI」，而要問「整個流程能不能被重新設計」。
  3. 建立 Agent 角色卡：目的、資料來源、可用工具、權限邊界、負責人、驗收標準。
  4. 導入前就設計治理：Mapping、Measurement、Manage，避免後續才補救。
  5. 培養知識工作者的三種能力：問題定義、脈絡提供、成果驗收。

5 頁摘要圖內容規劃

  1. 1/5：AI Agent 已從工具變成數位同事。
  2. 2/5：導入不是替換步驟，而是流程再造。
  3. 3/5：知識工作者的新價值是定義問題與驗收結果。
  4. 4/5：企業要用數位員工的方式管理 Agent。
  5. 5/5：未來趨勢：結果付費、多模態、AI for science。
