Palmier Pro + AutoIP MCP：AI 剪輯進入可視化時間軸

一套可視化 AI 剪輯工作流觀察：Palmier Pro 讓 Agent 進入剪輯時間軸，AutoIP MCP 補上生成素材能力。

重點摘要

  • Palmier Pro 的價值不只是「AI 幫你剪片」，而是讓 AI Agent 直接進入可視化剪輯器，操作時間軸、素材庫與預覽畫面。
  • 相較 Skill + ffmpeg 直接輸出影片，Palmier Pro 透過 MCP 操作剪輯軟體，保留時間軸與後續人工微調空間。
  • Palmier Pro 目前是 macOS／Apple Silicon 的開源剪輯器；編輯器、MCP server 與 in-app agent chat 開源，生成式 AI 處理則是服務端能力。
  • @autoip/mcp 補上素材生成端，可讓 Claude、Codex、Cursor 等 MCP client 呼叫文生圖、以圖生圖、對嘴影片、舞蹈影片與下載輸出。
  • 最值得觀察的是「可改造工作流」：開源剪輯器加上 Agent，可把常用效果、字幕、外框字或素材處理變成自己的外掛。

三種工具路線怎麼看

路線適合情境優點取捨
Skill + ffmpeg一句話產出影片，適合批次、自動化、固定範本快、容易部署、可重複不容易看時間軸，修改常要重跑
Palmier Pro + MCPAI 直接操作剪輯器時間軸看得到成果，可人工微調目前平台限制較明顯，需要 macOS 26 Tahoe / Apple Silicon
AutoIP MCPAI Agent 呼叫生成圖片、對嘴、舞蹈影片等素材補齊素材生成能力，可串進剪輯流程需要 AutoIP Pro 以上與 API key，任務輸出需認證下載

小河觀察

這則工具觀察的重點，不是「AI 能不能自動剪完」，而是剪輯成果是否能留在可理解、可調整、可擴充的工作空間。對創作者來說，可視化時間軸讓人保留最後判斷；對團隊來說，開源與 MCP 讓常見剪輯效果有機會沉澱成自己的工具與 SOP。

原文整理

我又發現了一套非常爽的工具palmier pro，這是套開源的AI剪接軟體

也就是你可以用你的claude或是gpt串這個工具幫你剪接。

這跟最近大家在討論的claude剪接有什麼不一樣呢？

一般claude剪接適用skill+ffmpeg來剪接跟燒錄字幕，palmier則是用claude的mcp來操作軟體剪接。

一般的claude剪接就是講完直接出一個影片給你，你也看不到時間軸也沒辦法直接做修正。

而用palmier剪接完畢後，就會跟剪映或是其他剪接軟體一樣，會打開介面給你看剪接的成果。

就是會有時間軸、素材庫、影片預覽的那種，直接可以看到剪接完成的樣子，我比較喜歡這種可以後面再次調整的感覺。

另外還有一個好處，因為這套軟體是開源的，所以你可以下載他的原始檔案自己做修改。

你要什麼樣的外掛效果，直接叫claude做給你就是了，直接把要的功能寫一寫非常方便。

就像palmier他原生的外框字有夠爛，我叫claude直接寫一個新的外掛，結果十分鐘就寫好了，整個效果就是我要的。

我用了兩天覺得非常順手，使用體驗很好，尤其是可以自己寫外掛工具，讓工作更流暢了。

我還是習慣可視化的編輯作業方式，如果你想要體驗claude剪接，也可試試cladue+palmier的組合
