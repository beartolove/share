要先學會 Markdown 才能用 Skill 嗎？Skill 建立、尋找與整理重點

官方來源網址：https://youtu.be/cZBfhYjN25M

重點摘要

  • 建立 Skill 不一定要先學會手寫 Markdown；更重要的是先說清楚任務目標、工作步驟與期望輸出。
  • Skill 的價值在於把會重複發生、具備固定規則的工作流程整理起來，讓 AI 之後穩定重複執行。
  • 現成 Skill 可以從官方目錄、別人整理的清單、GitHub 搜尋或 Find Skills 類工具開始找，不必每個都從零打造。
  • 不要把 Skill 當收藏品囤積；太多重複或過度規定的指引，會增加維護成本與 token 負擔。
  • 團隊導入 Skill 時，應定期檢查需求是否仍清楚、流程是否跑過、規則是否重複、輸出是否可驗證。

適合情境

會議記錄、固定格式報告、重複性資料整理、內部工作流程標準化。

導入提醒

共同規則放在 Agent 層，特定工作流程才放在 Skill；不要把每一步都寫死，保留模型依情境調整的彈性。
