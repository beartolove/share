Koboyo：給 Agent 與 PPT／網頁設計用的 7 萬多個手繪 SVG 圖庫

整理 Koboyo 手繪 SVG 圖庫對 Agent、簡報與網頁設計工作流的用途。

#科技及AI新知#AIAgent#MCP#SVG#簡報設計

官方來源網址：https://koboyo.com/icons

引用來源：Facebook 原貼文

重點摘要

  • Koboyo 是一個手繪風格 SVG 圖庫，官方頁標示共有 71,262 個免費 hand-drawn SVG icons。
  • 它適合常做 PPT、網頁、簡報模板或 AI 生成頁面的工作流，尤其能補足 Agent 生成設計時「找不到合適圖樣」的缺口。
  • 手繪黑白線稿風格清淡素雅，能中和常見 AI 設計過度油亮、科技感太重或裝飾過滿的問題。
  • Koboyo 提供 MCP 入口，可讓 Claude Code 等 Agent 在設計時直接搜尋與插入 SVG，而不是人工逐張下載。
  • 導入時仍要確認每個專案的授權需求與品牌一致性；SVG 很方便，但也要避免圖示風格混雜。

官方頁與截圖重點

官方標題Koboyo Icons — 71,262 free hand-drawn SVG icons
圖庫數量71,262 個圖示
截圖可見分類All icons、Face、Mark、Object、People、Scene、Solid
常見用途PPT、網頁、簡報、設計稿、Agent 自動化產出
MCP 指令claude mcp add --transport http koboyo-icons https://api.koboyo.com/v1-mcp

適用情境

適合什麼人？常用 Claude Code、Codex 或其他 Agent 做網頁／PPT 的人。
解決什麼痛點？不用為了版權或素材來源到處找 icon，可用同一套手繪 SVG 風格。
設計風格？清淡、素雅、黑白線稿、手繪感，適合降低 AI 設計的油膩感。
導入方式？把 Koboyo MCP 加到常用 Agent，讓 Agent 在製作時搜尋與插入 SVG。

Claude Code MCP 指令

claude mcp add --transport http koboyo-icons https://api.koboyo.com/v1-mcp

小河提醒

  • 圖庫好用，但正式商用前仍建議閱讀 Koboyo 的 License 頁面，確認專案授權需求。
  • 若整份簡報或網站都使用 Koboyo，視覺會比較一致；不要和太多不同風格 icon 混搭。
  • Agent 生成頁面時，可在設計規範中明寫「優先使用 Koboyo 手繪 SVG 圖示」。

原文整理

常要做PPT或網頁的Agent或人類，必用這個SVG圖庫！

現在網頁和PPT幾乎都是 Agent 在做了，至少我是如此。我只要給一個大綱，給一個範本，然後就會生成網頁或PPT的基礎，然後再修改就行。但有一個小煩惱，就是常常找不到合適的圖樣。

有時候Claude Code或Codex會說因為版權問題無法下載，舊版的Claude Code都可以，有點麻煩，但有了koboyo.com之後，這個問題就解決了。

收集了七萬多個手繪風格的SVG圖樣，讓你完全不需要到處找，很適合清淡素雅風格的設計。由於現在AI做的圖和設計都很油，這種清新風格的SVG真的可以讓你的PPT或是網頁為之一亮。

怎麼用？當然不是自己手動下載，koboyo.com有MCP哦！你只要在常用的Agent中加入MCP就可以在設計時插入這些SVG。舉例來說，如果是Claude Code，只要輸入：

「
claude mcp add --transport http koboyo-icons https://api.koboyo.com/v1-mcp
」

就可以加入MCP了。常常需要做PPT或網頁的人，甚至是繪圖工作者，千萬要讓你自己或是你的Agent試試看哦！
