OpenAI 宣布 AI Agent 外掛新標準：Agent Plugins

這支影片說明 Agent Plugins 如何把 Agent Skills 與 MCP servers 包成跨工具可攜的外掛格式，也提醒它目前仍不涵蓋 marketplace、權限、沙盒與信任機制。

#科技及AI新知#AI Agent#AgentPlugins#MCP#CodingAgent

來源影片：https://youtu.be/M3gHlwHKsBI?si=zzy5yW07RbJU9SpT

重點摘要

  • Agent Plugins 是新的開放打包格式，讓 Skills 與 MCP servers 可以一起被散布與安裝。
  • 核心資料夾結構很小：plugin.json、skills/、mcp.json；其他專屬功能仍交給各 client。
  • 影片示範把 Anthropic legal knowledge-work plugin 遷移成新標準，並在 Codex 裡看到 legal skills。
  • 目前限制是安裝與 marketplace loading 還不完全可攜，本機測試仍可能需要額外設定。
  • 企業導入時要把外掛視為供應鏈風險：來源、權限、MCP 連線與執行腳本都要審查。

一句話總結

Agent Plugins 不是要取代 MCP 或 Skills，而是把它們用共同資料夾結構包起來，讓同一組 Agent 能力更容易跨 Codex、ChatGPT、Cursor、GitHub Copilot、Kiro、VS Code 等工具流通。

關鍵觀察

可攜核心

plugin.json、skills/、mcp.json 是主要共通結構。

仍未標準化

安裝、marketplace、權限模型、沙盒與信任來源仍由各 client 自行處理。

示範價值

影片示範把既有 Anthropic plugin 遷移成新結構，再在 Codex 中使用。

導入提醒

越容易安裝外掛，越需要外掛供應鏈治理與權限審查。

Agent Plugins 與 MCP／Skills 的關係

元件負責什麼一句話理解
MCP連接工具、資料與外部服務讓 Agent 能呼叫外部能力
Agent Skills可重複使用的操作知識與流程告訴 Agent 怎麼完成特定任務
Agent Plugins把 Skills 與 MCP 設定一起打包讓一組能力可以跨多個 client 散布
