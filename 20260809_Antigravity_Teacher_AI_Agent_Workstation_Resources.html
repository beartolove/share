老師可以怎麼開始

新手入門

先看 AntiGravity 入門指引，建立 AI Agent、專案、提示與互動教材的基本概念。

環境設定

再看設定指南，依帳號、模型、瀏覽器、App、Add Context 等選單調整工作站。

教學應用

上傳教材或題庫，讓 Agent 協助生成題目、解析、互動網頁或測驗流程。

Skill 打包

把常用流程寫成 Skill，讓 Agent 在遇到特定任務時自動套用規格。

成果驗收

用密室逃脫或互動測驗成品驗證學生是否能真正參與、解謎與學習。

分享給老師時可以這樣說

如果還沒接觸 AI Agent，可以先從 Antigravity 入門指引建立基本概念；若已經想實作，則可從密室逃脫 Skill 開始，把既有教材轉成解謎式互動測驗，讓學生在闖關中學習。
