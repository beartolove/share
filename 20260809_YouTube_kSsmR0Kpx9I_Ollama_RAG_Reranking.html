Ollama RAG 準確度提升：用 Reranking 補上關鍵缺口

原始標題：Ollama 少了這個功能，RAG 準確度掉三成怎麼辦？一招搞定｜EP.05｜Alexandra Coding

這支影片說明 Ollama 做 RAG 時缺少 reranking 會造成找錯 chunk，並示範用 BGE reranker 或 Cohere Rerank API 補上第二道排序。

#科技及AI新知#RAG#Ollama#Reranking#LlamaIndex

來源影片：https://youtu.be/kSsmR0Kpx9I?si=CvdfKlVkiioqD0tx

重點摘要

  • Ollama 做 RAG 時，常見問題不是模型不會答，而是向量搜尋先找錯 chunk。
  • Reranking 的作用是第二道排序：先廣泛召回候選段落，再用 reranker 重新打分。
  • 本機 BGE reranker 適合內部知識庫與敏感資料；雲端 Cohere Rerank 則速度快、導入簡單，但要評估資料外送。
  • 實作時不要把 similarity_top_k 設太小，否則 reranker 沒有足夠候選段落可重排。
  • Reranking 能改善「候選裡有答案但排序錯」的問題；若知識庫本身沒有答案，仍需回頭補資料。

一句話總結

Reranking 是讓 Ollama RAG 從「找得到一些相關段落」變成「把真正相關段落排到前面」的關鍵補強。

關鍵觀察

  • 影片示範用 Ollama embedding 搭配 LlamaIndex query engine，再透過 postprocessor 接上 reranker。
  • BGE reranker-v2-m3 是本機多語言 reranker 選項；記憶體不足時可換較小模型。
  • Cohere Rerank API 適合快速試作，但敏感資料與公司內部知識庫需先確認資安政策。
  • 評估 RAG 改善效果時，應用固定測試集比較「只有向量搜尋」與「向量搜尋 + reranking」。

影片說明欄

Ollama 不支援重新排序（Reranking），導致 RAG 準確度常常卡在七成。這部影片教你用 BGE-Reranker 或 Cohere API 補上關鍵缺口，讓準確度飆升到九成以上。內附完整 Python 程式碼與對比實測數據。

本片用到的指令與連結

安裝套件：`pip install sentence-transformers llama-index llama-index-postprocessor-rankgpt-rerank`
LlamaIndex Reranker 設定範例：
```python
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader
from llama_index.postprocessor.rankgpt_rerank import RankGPTRerank
from llama_index.embeddings.ollama import OllamaEmbedding
documents = SimpleDirectoryReader('your_folder').load_data()
embed_model = OllamaEmbedding(model_name='nomic-embed-text')
index = VectorStoreIndex.from_documents(documents, embed_model=embed_model)
reranker = RankGPTRerank(top_k=5, model='BAAI/bge-reranker-v2-m3')
query_engine = index.as_query_engine(similarity_top_k=20, node_postprocessors=[reranker])
```
Cohere Rerank 替代方案：
```python
from llama_index.postprocessor.cohere_rerank import CohereRerank
reranker = CohereRerank(top_k=5, api_key='your-cohere-api-key')
```
模型下載：初次執行時自動下載，或手動使用 Hugging Face
