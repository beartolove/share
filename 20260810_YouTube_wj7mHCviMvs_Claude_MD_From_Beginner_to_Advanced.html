重點摘要

  • CLAUDE.md／AGENTS.md 是 AI coding agent 開工前會讀取的專案作業準則。
  • 規則要依作用範圍分層：個人偏好、專案共識、資料夾規則與本機私有設定。
  • slashinit 可以產生第一版，但要刪掉 AI 自己能找到、容易過期或不常用的內容。
  • 真正值得留下的是 AI 猜不到但不能搞錯的隱性知識：硬性規定、固定流程、連動關係、完成標準與資料位置。
  • CLAUDE.md 不是一次寫完的規格書，而是要隨模型、專案與團隊工作方式持續修剪的活的檔案。

一句話總結

CLAUDE.md 的價值不是寫多，而是把 AI 自己猜不到、每次都不能搞錯的規則放在最對的位置。

關鍵觀察

  • context window 決定 AI 看得到多少資料；instruction budget 則影響 AI 能同時顧好多少要求。
  • 長流程不該常駐在 CLAUDE.md，適合移到 skill；安全底線不該只靠提醒，適合交給 hook。
  • 如果同時使用 Claude Code 與 Codex，可以思考用單一來源維護規則，再讓另一份檔案 reference 它。
