KahootCLI：AI Agent 自動化 Kahoot 出題

一個給教師使用的 Kahoot 自動化出題 CLI：把 AI Agent 產題、配圖、瀏覽器操作與發布流程接起來。

引用來源：Facebook 貼文　GitHub：littleyi22/kahoot-cli

重點摘要

  • KahootCLI 用 Python + Playwright 驅動真實 Chrome，讓 AI Agent 或腳本自動建立 Kahoot 互動測驗。
  • 老師只要提供題目方向或 JSON 內容，工具可協助建立標題、填題幹與選項、搜尋配圖，並存成草稿或發布。
  • 支援多選測驗、是非題、簡答填充、排列解謎、文字雲與票選活動；其中部分進階題型需付費帳號。
  • 專案附有 SKILL.md，讓 ChatGPT Codex、Claude、Antigravity 等 Agent 可依 SOP 呼叫 CLI。
  • 登入設計採本機真實 Chrome Session，避免把密碼交給 Agent；但正式發布前仍建議人工預覽與審稿。

提醒：部分題型屬於 Kahoot 付費帳號功能；自動化能省時間，但正式發布前仍應人工審稿、預覽與確認權限。

自動化工作流程

1. 準備題目

AI Agent 產生符合格式的題目 JSON，或由老師提供題目素材。

2. 檢查 Session

先執行 check / doctor，確認 Python、Playwright、Chrome 與登入狀態。

3. 建立 Kahoot

用 create --content x.json 自動逐題填入，可選擇草稿或發布。

4. 人工把關

dry-run、審稿、預覽、確認進階題型帳號權限後再正式使用。

題型與帳號需求

quiz

多選測驗題｜免費｜2–4 個選項，需正確答案索引

true_false

是非題｜免費｜是／否選項，需正確答案

type_answer

簡答／填充題｜付費｜可列多個正確答案

puzzle

排列解謎｜付費｜恰好 4 個答案，依正確順序

word_cloud

文字雲｜付費｜開放式回應

poll

票選活動｜付費｜2–4 個投票選項

小河觀察

  • 這類 CLI 的價值不只在「匯入題目」，而是把 AI Agent 的產題能力接到真實教學平台操作。
  • SKILL.md 是關鍵：它讓不同 Agent 讀得懂工具邊界、JSON 格式、登入方式與執行 SOP。
  • 教育現場導入時，建議先把題目品質檢核、圖片版權與付費題型權限放進固定流程。
