open-slide：Agent 原生開源簡報框架

臺灣開源專案，讓 coding agent 用 React 元件產出簡報；適合技術簡報、產品 demo 與工程型內容。

#科技及AI新知#開源工具#AI Agent#簡報

官方網站：open-slide.dev｜GitHub：1weiho/open-slide

重點摘要

  • open-slide 是一套 React-first 的開源簡報框架，定位是「為 AI agents 而生的 slide framework」。
  • 它把每張投影片當成 1920×1080 畫布上的 React 元件，讓 coding agent 能直接用程式碼產出美觀簡報。
  • `@open-slide/cli` 可以用一個命令建立工作區，預先放好 `CLAUDE.md`、`.claude/skills/`、`.agents/skills/` 與起始投影片。
  • 特色不只是產生投影片，也包含視覺編輯、留言後由 Agent 套用修改、素材管理與靜態頁部署。
  • 比較適合懂 Node／React／coding agent 工作流的人；它是強大的開發者型簡報框架，不是完全零門檻的一般簡報 App。

GitHub stars 以查詢當下 GitHub API 約 6,245 顆星為準；貼文提到 6.1k，實際數字會持續變動。

工作流拆解

面向open-slide 的做法對使用者的意義
產生簡報用 coding agent 寫 React 投影片可以用自然語言驅動，也能回到程式碼精修
版面固定 1920×1080 畫布、自動縮放不被傳統範本綁住，適合客製視覺
工作區CLI 初始化 `slides/`、Skills、`CLAUDE.md`少掉大量環境與規則設定
迭代視覺選取、留言、`/apply-comments`人看畫面提需求，Agent 回頭改程式
素材assets panel、圖片與 logo 管理減少素材散落與重複整理成本

快速開始

npx @open-slide/cli init my-slide
cd my-slide
pnpm install
pnpm dev

小河觀察

  • open-slide 的重點不是「替你生簡報 App」，而是把簡報變成 coding agent 可以可靠修改的工程專案。
  • 對懂開發的人來說，它比傳統簡報工具更容易版本控制、重用元件與精修視覺。
  • 對一般使用者來說，門檻會在 Node 環境、React 思維與 agent 指令設計；正式簡報仍需要人工審稿。
