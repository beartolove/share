重點摘要

  • SayIt 是一款免費開源語音輸入工具；貼文主張搭配 Google Gemini 免費 API，可做到按住說話、放開自動貼上。
  • 安裝流程可拆成三步：下載 SayIt、取得 Gemini API Key、在 SayIt 設定 STT 與 LLM。
  • 官方頁建議 STT 使用 Whisper Large V3 Turbo，LLM 服務切到 Google Gemini，整理模式選「積極」。
  • 日常使用方式很直覺：游標點到輸入框，按住右 Alt 說話，放開後自動整理並貼上。
  • 導入時要注意 API Key 保護、macOS 輔助使用權限，以及避免把機敏資料直接唸進雲端服務。

一句話總結

SayIt 的價值是把「說話 → 轉錄 → LLM 整理 → 自動貼上」串成一個快速語音輸入流程。

導入提醒

  • API Key 不要截圖公開，也不要貼到不可信任的地方。
  • 如果是公司或學校環境，建議先確認資訊安全政策與可用雲端服務範圍。
  • 涉及個資、學生資料、合約、病歷或內部機敏資訊時，先不要直接語音輸入到雲端模型。
  • 先用非機敏情境小範圍試用，例如備課草稿、一般訊息、個人筆記。
