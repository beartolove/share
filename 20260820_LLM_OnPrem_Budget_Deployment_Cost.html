企業導入 LLM 的錢怎麼花：地端部署與 2000 萬預算題

這篇把企業導入 LLM 的部署路線與成本估算攤開來看：不是先問要不要地端，而是先問資料敏感度、用量、併發與三年總成本。

重點摘要

  • 貼文用「500 人企業、年度 2000 萬預算」作為開場問題，核心是討論企業導入 LLM 時，錢應該花在 API、私有雲、開源雲端 GPU，還是開源地端。
  • 原文把部署路徑分成四類：官方 API、閉源私有雲、開源雲端 GPU、開源地端；差異在速度、安全、成本、資料控制權與維運責任。
  • 以原文假設估算，官方 API 第一年約 5,067 萬，閉源私有雲約 5,574 萬，開源雲端 GPU 約 2,346 萬，開源地端約 3,840 萬。
  • 地端部署不是只買 GPU；原文估算 500 人場景約需 375 併發、兩組八卡 GB300、前置 2,880 萬與每月 80 萬維運。
  • 如果公司是 IC 設計等核心資料高度敏感產業，原文結論偏向開源地端，但整體預算可能要約 5,800 萬，2000 萬明顯不夠。

小河提醒

  • 這些數字是貼文中的估算情境，不等於所有企業都會得到同樣結果。
  • 真正決策要補上電力、機房、網路、HA/DR、監控、資安稽核、模型治理、MLOps、人才與採購折舊。
  • 對熊熊的情境來說，這篇很適合拿來當「AI 平台預算盤點」的討論範本：先問資料敏感度，再估用量、併發與三年總成本。

原文整理

今天在 GAI 小聚聊了地端部署的議題，這場演講想帶給大家的是：企業導入 LLM 的錢，到底應該怎麼花。一開始丟出的問題是：假如你要進入某家公司當 AI 長，公司有 500 人，今年預算是 2000 萬，你要怎麼分配這筆資源？

■ 開源模型逼近前沿，四條路線怎麼選

先看能力。Artificial Analysis Intelligence Index 上，Claude Opus 5 是 63 分、Claude Fable 5 是 62、GPT-5.6 Sol 是 61，開放權重的 Kimi K3 是 60——只差榜首 3 分，已經站進前沿能力群。這個時間點考慮開源模型是個合適的進入點。

用 LLM 部署在企業裡，有四條路徑可以選。橫軸是雲端跟地端，地端意味著你能擁有自己的權重、自己的機房；縱軸是開源跟閉源，開源嚴格來講是開放權重，你可以下載、可以部署、可以微調。

最常見的是官方 API，優點是能快速導入，但核心資料要避開這條路，適合求快的新創公司。

想讓安全性再往上一點，還有私有雲的方案，可以在裡面做資料隔離，但它終究不是自家機房，安全性還是有人存疑，通常適用中大型企業的非核心資料，像行政公文、email 這類；程式碼這種比較機敏的東西，一般公司不會走這條路。

開源模型也不一定要地端部署，可以用雲端 GPU，例如 OpenRouter 這類服務，優勢是沒有建置費用，還能選比較便宜的模型，適合對成本敏感的網路服務，但要注意服務的穩定度。

最後，開源＋地端，資安等級最高，資料跟權重都留在地端，但要同時負擔建置成本跟後續維運，通常適用大型企業的核心資料。

■ 把帳攤開來算

用量假設：公司規模 500 人，每人每週開發 30 小時，這是一週 40 小時工時裡的 75%，一年下來大約 78 萬次任務。價格假設：閉源用 Claude Opus 5，每任務約 2.03 美金；開源用 Kimi K3，每任務約 0.94 美金；私有雲加 10% 合規溢價。

官方 API 一開始沒有建置成本，第一年大約 5,067 萬，三年下來約 1.52 億。閉源私有雲用量一樣，月費上加 10% 合規溢價，第一年約 5,574 萬，三年約 1.68 億——合規是要付錢買的。開源＋雲端 GPU 同樣沒有建置成本，Kimi K3 又比 Opus 5 便宜不少，第一年大約 2,346 萬，只有官方 API 的 46%。

■ 地端要蓋多大

地端是兩組八卡 GB300，前置 2,880 萬、每月維運 80 萬。500 人不會同時都在跑 agent，前面假設一週 40 小時裡有 30 小時在開發，也就是 75%，所以任一時刻大約是 375 個併發，不是 500。供給端，GB300 一張卡大約撐 33 個併發（原始基準是拿參數量較小的模型測的，換成 Kimi K3 要按參數量往下修），一個副本八張卡大約 260 個併發，375 除以 260 是 1.4，一副本不夠，得要兩副本、共十六張卡，這就是 2,880 萬建置成本的來源。

縱使一開始建置成本比較高，因為能用比較便宜的 Kimi K3，又不用付雲端平台的保管費，地端第一年（2,880 萬加 12 個月維運，約 3,840 萬）其實已經低於官方 API 第一年的 5,067 萬；跟官方 API 比，大約第 8.4 個月就追平；跟開源＋雲端比，要到第 24.9 個月。而且不只基礎建設，還要有 AI 軟體跟 SaaS：Wasabi 2026 的調查指出，企業 AI 預算大約 66% 花在基礎建設，33% 花在 AI 軟體跟 SaaS 上。

■ 回到開場那一題

開源加地端還有四個好處：資料隱私（產業有資料保護要求時非常重要）、成本（長期使用較便宜）、工程穩定性（自行部署能把版本定住，不會因為某家廠商突然把某個 API 下架，整個工作流就得重新來過）、客製化（可以用 fine-tune 把模型調得更好，但資料、算力、人才三者缺一不可，成本還會再往上加）。

四條路線，各自有適合的公司。回到開場那一題，如果假設是一間 IC 設計公司，需要高度資料保護，就得走地端：第一年基礎建設加維運大約 3,840 萬；照 66% 的基礎建設佔比往回推，整體預算大概要 5,800 萬。原本設定的 2000 萬預算，其實遠遠不夠。
