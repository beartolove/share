核心檔案 Skill 適合基本讀取與整理；如果要讓 Agent 產出 Word、PDF、Excel 或圖片成果，就要依任務選擇進階工具。

重點摘要

  • 進階檔案處理 Skill 的重點不是「一次安裝全部」，而是讓 Agent 先判斷任務，再選對工具。
  • Word、PDF、Excel、圖片處理分別對應不同 Python 套件，避免用單一工具硬做所有事。
  • 官方頁特別強調可在本機端執行，適合學校行政、備課、成績表與素材整理等重複流程。

小河觀察

這組工具很適合做成「任務導向」的 Agent Skill：使用者不需要記每個套件細節，只要說明要改 Word、合併 PDF、整理 Excel 或處理圖片，Agent 再選工具與建立最小依賴環境。
  • 先小任務試跑：第一次不要直接處理全校資料，先拿 3～5 筆樣本驗證格式。
  • 保護個資：學生成績、公文與個資檔案應優先走本機端處理，必要時先去識別化。
  • 人工確認：Agent 可批次產出，但正式交付前仍要抽查頁碼、欄位、姓名與數字。

原文整理

#進階文件處理Skill 核心文件 Skill 適合基本讀取與整理；如果要進一步製作 Word、PDF、Excel 或圖片成果，就可以使用這組進階工具。 📄 文件與 PDF處理 - python-docx：建立、讀取與修改 Word 文件。 - ReportLab：產生 PDF、報告與格式化文件。 - pypdf：合併、分割、旋轉與整理 PDF。 - pdfplumber：擷取 PDF 表格、文字與版面資料。 📊 表格與圖片處理 - openpyxl：讀取與編輯 Excel 活頁簿。 - pandas：清理、分析與整理大量表格資料。 - Pillow：處理圖片尺寸、格式與基本轉換。 Agent 會先判斷任務需求，再建議需要使用哪一個工具，不必一開始全部安裝。
