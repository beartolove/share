用 Claude Skill 低成本生成圖片與影片

這支影片示範如何不再綁多個 AI 圖片／影片訂閱，而是把 FAL API 接進 Claude 或 ChatGPT 桌面版，建立一個可重複使用的 Skill。流程包含：建立專案資料夾、準備完成檔與參考圖、取得 FAL API Key、比較模型價格、設定圖片與影片生成模型、讓 AI 先優化提示詞再送出、最後甚至把 Skill 包成桌面 App。核心提醒是：API 金鑰要妥善保存，生成前要讓 AI 先給人檢查提示詞，影片參數要用一問一答確認，成本則用實際生成量控管。

  • 圖片與影片可共用同一套流程
