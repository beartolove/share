一句話總結：
這支影片示範如何用 OpenRouter 免費模型接到 Claude Code，讓免費模型在 Claude Code harness 裡執行檔案搜尋、寫入、工具呼叫與驗證；實測結果是「可用但很慢」，適合輕量知識工作與額度用完時的備援，不適合敏感資料與深度工程。

核心重點：
1. 設定方式：建立 OpenRouter API key，改 Claude Code settings 的 env 與模型名稱，桌面版 Claude Code 不適用。
2. 模型選擇：可用 Stealth OX Alpha 或其他 free model，也可用 OpenRouter free models router，但免費模型會變動。
3. 安全提醒：匿名供應者模型不適合公司機密、客戶資料、API key 或私密知識庫。
4. 實測結果：landing page、YouTube 頻道報告、社群支援分析都能做，但常遇到 timeout，速度遠慢於 Claude。
5. 適合場景：輕量知識工作、資料整理、低敏感任務、額度用完時的臨時備援。
6. 不適合場景：大型 app、深度工程、多 Agent orchestrator、需要高度穩定與快速完成的工作。

小河提醒：
免費模型不是免費的魔法，它只是把成本從金錢轉成時間、穩定性與資料風險。若要在公司情境使用，應把它放在明確邊界內：低敏感資料、小任務、可重試、可人工驗收。

5 頁摘要圖主軸：
1. 免費模型也能進 Claude Code harness。
2. 設定路徑：OpenRouter key + settings。
3. 實測優點：能用工具、技能與專案脈絡。
4. 實測限制：慢、timeout、資料風險。
5. 企業使用建議：當備援，不當主力。
