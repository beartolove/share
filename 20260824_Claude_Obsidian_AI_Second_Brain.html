Claude Code 外掛：打造 Obsidian 自動化第二大腦

把 Obsidian vault 視為本地 Markdown 知識庫，讓 Claude Code 協助讀寫、連結、查詢與維護；重點是 local-first、來源可追溯，以及把操作放在 Claude Code／Agent Skill 工作流中。

重點摘要

  • 這是什麼：claude-obsidian 是給 Claude Code／Agent Skills 主機使用的 local-first 知識系統，讓 Obsidian vault 維持為一般 Markdown、JSON 與來源檔案。
  • 核心價值：它不只把對話存成筆記，而是保留來源、追蹤 claim/source ledgers，讓知識可以被查詢、整理、維護與再次使用。
  • 主要功能：README 提到 /claude-obsidian:wiki、wiki-ingest、save、wiki-query；延伸能力包含 autoresearch、canvas、wiki-lint、wiki-retrieve 等。
  • 安裝提醒：官方文件強調產品 checkout 與使用者 vault 要分開；這是 Claude Code 外掛／Agent Skill 工作流，不是 Obsidian 社群外掛。
  • 適合對象：適合同時使用 Obsidian 與 Claude Code，並希望把研究、資料整理、斷頭連結檢查與知識庫維護交給 AI 協助的人。

【Claude Code 外掛：打造 Obsidian 自動化第二大腦】 適合同時使用 Obsidian 與 Claude Code 的開發者。 讓 AI 直接讀寫你本地的 Markdown 筆記，自動整理知識庫與斷頭連結。 基於 Karpathy 的 LLM Wiki 架構設計。 直接在本地端的原生 Markdown 檔案上進行操作。 支援 /autoresearch 自動進行主題研究。 也能用 /save 將對話內容自動結構化成獨立筆記。 特別注意這是在 Claude Code 終端機運行的外掛。 不需要在 Obsidian 的社群插件商店安裝。 執行指令即可完成安裝與部署。 項目連結： https://github.com/AgriciDaniel/claude-obsidian
