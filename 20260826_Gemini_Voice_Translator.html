原文整理

電腦王阿達文章介紹作者 vibe coding 的第二個 App「Gemini 即時語音翻譯」，功能是讓使用者出國旅遊時可以用說話直接與外國人溝通。使用者需要自行申請 Gemini API Key，並在 App 初次開啟時設定 API Key 與語音。 作者表示，這個 App 的起因是 Google 翻譯在美國、日本已開放即時語音翻譯功能，但中文區尚未開放，因此基於先前 Web App 文章自行開發 App。App 可設定來源語言與目標語言，按下 START TRANSLATING 後，會要求麥克風權限，接著進行語音辨識、即時翻譯、語音播放與字幕顯示；對方說的話也可以翻譯回來。 費用方面，App 本身免費、無廣告，但使用者需提供自己的 Gemini API Key。作者使用 Gemini 2.5 Flash，認為一般旅遊使用成本很低；若使用 Google AI Studio 的 Free tier 專案，免費額度用完通常只會冷卻。不過文章也提醒，如果 API Key 所在專案已經綁定計費，超出免費額度後可能產生費用，因此最好確認 API Keys 列表是否標示 Free tier，或另外建立一個不綁信用卡的小帳／專案。 文章中提供 Android / Google Play 與 iOS / App Store 下載連結，也提到 Web App 版與 Gemini API 免費額度相關文章。文中對 iOS 版本的敘述有前後不完全一致處，因此實際可用狀態仍應以 App Store 頁面為準。
