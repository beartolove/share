WebMCP 與 Codex 瀏覽器外掛｜網站主動提供工具給 AI Agent 呼叫

這支影片實測新的瀏覽器外掛與 WebMCP：前者讓 Codex 進入瀏覽器側邊欄理解頁面，後者讓網站把能力宣告成可呼叫工具，讓 Agent 不必只靠猜 DOM 或模擬點擊。

來源影片：https://youtu.be/Wl9tcoVuLjA?si=PvIZMOomF-YFREN0
建立時間：2026-08-29（Asia/Taipei）

#科技及AI新知#WebMCP#Codex#BrowserPlugin#AIAgent

重點摘要

  • 新瀏覽器外掛讓 Codex／ChatGPT 可在瀏覽器側邊欄工作，直接讀取目前網頁、選取文字與其他分頁上下文。
  • 外掛功能包含：設定任務目標、計畫模式、模型與速度選擇、語音輸入、頁面分析、圖像理解、文字翻譯與工具串接。
  • WebMCP 的關鍵不是讓 Agent 更會點按鈕，而是讓網站主動宣告可呼叫工具，降低 DOM 猜測與模擬點擊。
  • 影片 Demo 顯示站點可提供列出、搜尋、讀取、建立、更新檔案等工具，讓 Codex 直接建立或修改網站內容。
  • 完整流程需要工具宣告、瀏覽器註冊表、權限門、模型選工具與產生參數、來源頁綁定、執行結果回傳。

功能、作法與範例

圖卡功能作法範例
新外掛不只是聊天框ChatGPT／Codex 直接進入瀏覽器側邊欄，讀取當前頁面上下文。在桌面 App 的 Computer Use／瀏覽器設定中啟用 Chrome 外掛。在論文頁旁邊打開側邊欄，直接請 Codex 分析全文。
側邊欄能設定任務與模式可設定目標、使用計畫模式、選模型、調整推理與速度，甚至錄製 Skill。開啟外掛後，在側邊欄輸入任務並選擇模式與模型。選 GPT-5.6、Medium 推理與 Fast 速度來分析頁面。
網頁內容直接變上下文不用複製貼上整篇內容，讓 AI 直接讀當前網頁。在瀏覽論文或文章時，把該頁帶入 ChatGPT／Codex 對話。要求它說明論文概念、真正問題、實驗結果與最終判斷。
選取文字與圖片也能問外掛可處理頁面中的選取段落與圖片內容。選取文字或指定圖像，再用自然語言要求解釋、翻譯或分析。選取英文摘要翻成中文；指定論文圖表請 AI 解讀。
外掛可串接 Notion 等工具分析結果可以交給已連接的工具沉澱成筆記。在對話中選擇 Notion 外掛，要求把分析報告儲存成結構化筆記。把論文分析轉成 Notion 中文筆記並驗證儲存成功。
多分頁可以聯合分析不只看單一頁面，也能引用已開啟的其他分頁。用 @ 符號或分頁選擇，把 GitHub 倉庫等分頁加入上下文。結合論文頁與 GitHub 專案頁，詢問專案安裝方式。
WebMCP 讓網站主動提供工具網站把自身能力宣告為可呼叫工具，降低 DOM 猜測與模擬點擊。網站用 JS 模組宣告工具名稱、描述與 input schema。本地筆記網站向 Codex 暴露列出、搜尋、讀取、建立、更新等 10 個工具。
站點工具可建立與更新內容Agent 可直接呼叫網站工具完成寫入，不必在畫面上慢慢點。使用者用自然語言下任務，模型選工具、產生參數，經確認後派發。請 Codex 寫一篇 WebMCP 使用筆記，並建立檔案存進網站。
WebMCP 也能做創作型任務網站可暴露設計、調色、設定尺寸等工具給 Agent。Agent 呼叫站點提供的設計工具，而不是猜畫布按鈕。讓 Codex 設計一張 WebMCP 宣傳卡片，呼叫重置、尺寸、背景色與強調色工具。
完整流程需要權限門工具宣告、註冊表、權限審查、來源綁定與結果回傳缺一不可。瀏覽器維護工具表；呼叫前審查確認；執行後把結果回到模型上下文。使用者一句自然語言，最後轉成站點工具呼叫與可視化結果。

影片中的範例

  • 論文分析：在論文頁旁開側邊欄，要求說明概念、研究問題、實驗結果與判斷。
  • 圖像理解：指定論文圖表，請 AI 解讀圖中內容。
  • 文字翻譯：選取英文摘要，直接請 AI 翻成中文。
  • Notion 沉澱：把論文分析轉成結構化中文筆記並存入已連接工具。
  • 多分頁分析：把論文頁與 GitHub 專案頁一起加入上下文，詢問安裝方式。
  • WebMCP 筆記 Demo：請 Codex 寫一篇 WebMCP 使用筆記，並建立檔案存入網站。
  • WebMCP 更新 Demo：要求為筆記加入更多 emoji 與內容，Codex 呼叫更新工具完成。
  • 創作型 Demo：讓 Codex 呼叫站點工具設計 WebMCP 宣傳卡片。

落地提醒

  • WebMCP 不是單純讓 Agent 更會點，而是讓網站提供明確、結構化的工具介面。
  • 權限門與使用者確認不可省略，否則網站工具越強，風險也越高。
  • 目前仍是早期支援，真正落地取決於瀏覽器、網站與工具生態是否跟進。
