重點摘要

1

這份 awesome-agentic-ai-zh 把 AI Agent 學習整理成 8 個階段，從 LLM、token、工具呼叫一路走到 multi-agent 協作。

2

路線分成 Track A 與 Track B：前者適合想把 Claude Code 這類 CLI Agent 用順的人，後者適合想從零打造 Agent 的開發者。

3

專案整理 240+ 精選 project、MCP + Skill 目錄、23 個練習資料夾，並涵蓋 Ollama、llama.cpp 等本地 LLM 路徑。

4

作者提醒練習資料夾裡的 starter.py 是完整解答，不是 TODO 骨架；真正的學習方式是自己重寫，卡住再對答案。

5

這不是三天速成清單，而是一條可規劃時間走完的學習路線：Track A 約 8–10 週，Track B 現實約 5–7 個月。

Track A：CLI Power User

約 8–10 週

Track B：Agent Builder

想理解 Agent 架構、工具呼叫、記憶、RAG、多 Agent 與 MCP server 實作。

最少 16–22 週；現實 5–7 個月，每週 5–8 小時

建議不要只收藏連結：先選 Track A 或 Track B，排出每週固定 5–8 小時，並用「自己重寫練習」取代只看解答。

🚀 免費又完整的AI Agent 繁體中文學習地圖來了！＃收藏分享或轉給正在自學的朋友！

最近在 GitHub 上看到一份 ＃繁體中文 資源，可能是我近期看過含金量最高的 AI Agent 自學地圖，建議大家規劃時間來學習整個架構！

先小科普：Agent，就是「不只回答問題，還能自己規劃步驟、呼叫工具、把任務做完」的 AI，跟一問一答的 ChatGPT 不是同一類。

博士生 WenyuChiou，把散落在 YouTube、論文、國外部落格的東西，整理成一份叫 awesome-agentic-ai-zh 的路線圖，MIT 授權，完全免費。

這幾個月常被問「想學 AI agent 到底要從哪開始」，過去我只能東丟一個連結、西丟一篇文章，拼不出一條完整的線。這份直接把答案整理完了。

🔑 先幫大家摘要這在學什麼

▸ ８個階段，從「LLM（大型語言模型）是什麼、token 怎麼算」一路到 multi-agent 協作，循序漸進，不是丟一堆連結叫你自己拼

▸ 分成兩條路線：Track A 給「只想把 CLI agent（像 Claude Code）用順」的人，Track B 給「想從零打造自己 agent」的人，共用基礎再分岔

▸ 240＋個精選 project，每個附星等、適合誰、教什麼、怎麼跑，連本地 LLM（Ollama、llama.cpp）都涵蓋

▸ MCP（讓 AI agent 能呼叫外部工具的協定）＋ Skill 完整目錄，收了 81＋條，還涵蓋中文 AI 生態（DeepSeek、智譜、Kimi）

▸ 每階段附基礎練習，dual-path 對照 Ollama 跟 Anthropic SDK 兩種寫法，不是只丟 code 叫你抄

▸ 依身分再分五條延伸路線：研究員、開發者、老師、知識工作者、日常使用者，各自對應到自己的痛點

＃以下算彩蛋嗎 ・這裡面有練習資料夾，你看到的 starter. py 其實是「完整解答」不是 TODO 骨架，但作者有提醒，如果 clone 下來直接看過、跑過 test 就會誤以為自己學會了，正確做法是自己重寫一遍，卡住才回去對答案

・Track B 主幹寫得很老實，最少 16 到 22 週，現實抓 5 到 7 個月（一週投 5 到 8 小時），沒有幫你灌水成「三天速成」#有心人真的可以幫自己規劃一下

・不是只有框架，連 Claude Code 生態（MCP、Skills、Plugins、Subagents）都整套收進去，等於把我平常在講的東西也系統化整理了一份
