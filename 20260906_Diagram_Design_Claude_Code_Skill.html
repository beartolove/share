Claude Code 畫圖 Skill：diagram-design 憑什麼沒有 AI 味

diagram-design 不是靠更強模型讓圖變好，而是把「刪除、留白、品牌色、節點密度、連線規則、taste gate」這些設計判斷寫進 Claude Code Skill，讓 AI 畫圖不再像通用模板。

來源影片：https://youtu.be/rq4EHbqaaAk?si=qnW2C-qNtTSwViqJ

GitHub repo：https://github.com/cathrynlavery/diagram-design

重點摘要

  • 同樣提示詞，Skill 規則會改變輸出品質。 影片用兩張 AI 生成圖對比：差別不是模型，而是 diagram-design 讀懂程式碼、取捨節點、套用品牌視覺與品味檢查。
  • 它會先讀程式碼再畫架構圖。 例如 Express 入口、下單路由、email 是否真的寄出、await 呼叫順序等，Skill 會把程式碼關係轉成圖面重點。
  • 品牌化不是手動挑色，而是從網站萃取設計 token。 影片示範用網站取得紙底、墨色、次要文字、強調色、連線色等角色，並把它存成 profile，方便不同客戶／專案切換。
  • Mermaid 舊圖可以被翻新。 Skill 會先解析 Mermaid，建立節點、邊、入口、終點與中心節點的檢查表，再重繪成更有編輯品質的圖。
  • 它不只給工程師用。 影片也示範產品經理用四象限圖開會，把七個功能放進優先級視覺，並把最值得先做的專案用單一強調色凸顯。
  • 沒有 AI 味的核心是不可談判規則。 例如「最高品質的動作通常是刪除」、強調色最多用在 1–2 個元素、目標密度 4/10、連線不能斜、座標與間距要對齊 4px 網格、輸出前跑 taste gate。
  • 工具邊界清楚。 HTML/SVG 可直接在瀏覽器看；PNG 匯出需要 Playwright。當依賴未安裝時，Skill 會提供安裝方式，但不會自動替你動系統環境。

一句話總結

diagram-design 不是靠更強模型讓圖變好，而是把「刪除、留白、品牌色、節點密度、連線規則、taste gate」這些設計判斷寫進 Claude Code Skill，讓 AI 畫圖不再像通用模板。

關鍵觀察

  • 影片真正值得學的不是「裝一個畫圖工具」，而是 Skill 怎麼把作者的設計 taste 變成可執行規則。
  • 對企業或團隊來說，這類 Skill 的價值在於把「怎麼畫才不醜」從個人經驗變成可複用流程。
  • 好的 Agent Skill 不是只堆功能，而是明確寫出不可妥協的品質門檻與輸出邊界。

## 5 頁摘要圖規劃

### Page 1/5：不是模型變強，是規則變清楚

畫面文字：

  • 同一句提示詞
  • 兩種輸出品質
  • 差別在 Skill 規則
  • 1/5

### Page 2/5：先讀懂，再決定畫什麼

畫面文字：

  • 讀程式碼
  • 找入口與路由
  • 分辨真正重點
  • 2/5

### Page 3/5：品牌色變成可重用 profile

畫面文字：

  • 網站取色
  • 設計 token
  • profile 存檔
  • 3/5

### Page 4/5：taste gate 擋掉 AI 味

畫面文字：

  • 刪除多餘節點
  • 強調只留 1–2 個
  • 連線不走斜線
  • 4/5

### Page 5/5：導入提醒

畫面文字：

  • 先定義圖的目的
  • 保留品牌規則
  • PNG 需 Playwright
  • 5/5

適合使用情境

  • 技術架構圖、流程圖、時序圖、狀態機、資料流圖需要快速變成可讀又有設計感的視覺稿。
  • 團隊有固定品牌色，希望 AI 產圖不要每次都像不同模板。
  • 需要把舊 Mermaid 檔案翻新成可放簡報或檔案的圖。
  • 想研究如何寫高品質 Claude Code Skill，把 taste、品質規則與工具邊界寫清楚。

導入提醒

  • 不要把它當成「一鍵生圖魔法」。它比較像把設計規範、圖型選擇與品質檢查流程交給 Agent 執行。
  • 圖面越複雜，越需要先說清楚讀者要看什麼；若節點超過 9 個，應考慮拆成兩張圖。
  • 若要匯出 PNG，需先處理 Playwright / Chromium 依賴；不要讓 Agent 未確認就自動修改系統環境。

Repo 補充資訊

  • repo：https://github.com/cathrynlavery/diagram-design
  • 授權：MIT
  • 定位：Agent Skill / plugin，產出自包含 HTML + SVG editorial diagrams。
  • 公開資料顯示支援 Claude Code、Codex、Pi、Factory Droid、Kiro、OpenCode 等 Agent Skills-compatible hosts。
  • GitHub / SkillsLLM / 說明欄對圖型數與 stars 有時間差；本頁避免把 stars 當固定事實，只保留「熱門開源 Skill」的脈絡。

影片說明欄重點與連結

影片說明欄指出，本集實測 diagram-design 的五種場景：讀專案程式碼生成架構圖、從網站提取品牌色、用 import-mermaid 翻新舊 Mermaid 流程圖／時序圖／狀態機、畫產品經理開會用的四象限優先級圖，以及用 export-diagram 匯出 SVG / PNG。

  • diagram-design：https://github.com/cathrynlavery/diagram-design
  • 安裝：`/plugin marketplace add cathrynlavery/diagram-design` → `/plugin install diagram-design@diagram-design`
  • Claude Code：https://claude.com/claude-code
  • Playwright：PNG 匯出使用，需另行安裝相關依賴。

風險提醒

本頁整理的是工具展示與開源專案資訊；安裝第三方 plugin / Skill 前，仍應檢查 repo 來源、授權、更新狀態、依賴與安全性。若在公司環境導入，建議先在測試專案驗證輸出品質、權限邊界與匯出流程。
