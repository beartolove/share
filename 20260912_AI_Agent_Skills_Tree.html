重點摘要

  • 核心觀念：頂級玩家的差距不在工具操作，而在腦中是否有一張能判斷問題落點的 Agent 知識地圖。
  • 單體架構：從自主性、Agentic Loop、Harness、Context Window 到記憶與 RAG，構成 Agent 能思考與行動的底座。
  • 行動能力：Tool Use、Function Calling、MCP、Computer Use 與 Code Interpreter，讓模型可安全連接並操作外部世界。
  • 協作治理：多 Agent、Subagent、Orchestrator-Worker、Human-in-the-Loop 與 Guardrails，決定何時分工、何時停下與何時由人把關。
  • 持續改善：Planning、Self-Reflection、Observability、Evals 與自主性光譜，讓團隊能量測、修正並設定合適的授權邊界。

從單體到協作

  • 先建立 Context、記憶與工具能力。
  • 任務變複雜時，再考慮 Subagent 與分工。
  • 分工不是越多越好，要看任務獨立性與整合成本。

企業導入提醒

  • 高風險動作保留 Human-in-the-Loop。
  • 用 Guardrails 限制輸入與輸出邊界。
  • 以 tracing 與 Evals 驗證，而非只憑感覺判斷。
