Gemini Notebook Cloud Computer：讓 AI 寫程式把資料變視覺化

NotebookLM 更名為 Gemini Notebook 並新增 Cloud Computer，讓 AI 能自行執行程式與 Python，把來源資料轉成地圖、圖表、GIF 與 PDF。

重點摘要

  1. Cloud Computer 是內建小電腦：AI 可存取它執行程式、計算或呼叫 Python 函式庫，做出原本做不到的成果。
  2. 突破 Studio 限制：Studio 只能產生語音／影片摘要、心智圖、投影片、字卡等現成項目；Cloud Computer 可自選並客製格式。
  3. 支援多種輸出：官方點名 PDF、Google Docs、投影片、Markdown 等（僅部分清單）。
  4. 三個示範：歐洲再生能源地圖、開源 LLM 圖表轉 GIF、iPhone 與 Pixel Fold 尺寸比較 PDF。
  5. 目前仍有邊界：建立網站或互動式內容尚不可行，部分格式需多次嘗試才成功。

使用流程

步驟動作
1打開筆記本，在聊天區貼上提示詞（例如「產生歐洲再生能源進展地圖，各國依比例上色」）
2送出後 AI 啟動 Cloud Computer 執行，視複雜度需等候一段時間
3結果顯示於右側，可用「更多選項」下載到裝置，跨專案重用

可以拿來做什麼

  • 把資料做成客製化視覺圖：地圖著色、比較圖、趨勢圖。
  • 產出可下載、可重用的 PDF／Docs／投影片／Markdown。
  • 用 GIF 動畫等動態呈現強化資料故事性。

使用提醒

Cloud Computer 的可用技能官方未完整公布，部分需求（如互動網站）目前尚無法達成；複雜格式可能需多次調整提示詞。功能持續更新，實際能力以 Gemini Notebook 現況為準。
