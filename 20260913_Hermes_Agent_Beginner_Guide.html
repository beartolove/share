重點摘要

  1. 定位是「數位員工」而非臨時工：不像用完即關的工具，Hermes 能長期陪伴、記住你的習慣與工作方式。
  2. 人設（Profile）：可自訂對話風格、語氣與表情，套用後自動建立對應的機器人。
  3. 工具（Tools）：外掛式加載（如網頁抓取），可訂閱官方額度或自備 API；入門用內建免費工具即可。
  4. 記憶（Memory）：依對話自動描繪使用者畫像，記住身份、偏好與作業系統習慣，越用越懂你。
  5. 通訊串接與排程：可接飛書、微信，用手機指派任務；能設定定時任務（如每天匯總 GitHub 生成日報）。
  6. 網關（Gateway）：像前台管家，把訊息與排程分派給 Agent 與大模型；可跑在本地或雲端。

四大模組一次看懂

模組角色
Profile 人設決定機器人的風格、語氣與身份
Memory 記憶累積使用者畫像與偏好，長期個人化
Tools 工具外掛能力（如網頁抓取），彈性計費
Gateway 網關調度通訊訊息與定時任務，可本地或雲端

入門建議

  • 登入後第一件事：到設定填入大模型供應商的 API Key（如 DeepSeek），也可先用免費模型。
  • 工具額度與大模型 Token 費用是分開的：官方會員針對工具額度，大模型 API 自行配置。
  • 初學者不必急著付費，先用內建免費工具與本地網關即可上手。
  • 串接微信／飛書只是把它當成「操作 Hermes 的對話介面」，不是讓 AI 代你回覆真人。

使用提醒

介面、登入選項、工具與計費方式可能隨版本更新而異；實際操作與費用請以 Hermes 官方與各服務商現況為準。
