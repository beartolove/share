LM Studio Bionic 的 Skills 功能讓你用自然語言描述任務，由本機 AI 自動生成可重複使用的指令集，搭配弱一點的模型執行，達到速度更快、Token 更省、可靠性更高的自動化效果。
  • 1LM Studio Bionic 是全新 Agentic AI 工具：與原本的 LM Studio 完全不同，主打 AI 代理人工作流程；可至 lmstudio.ai 下載，確認選 Bionic 版本。
  • 2Skill 是可重複使用的指令集：可包含文件、程式碼、命令提示詞；儲存在全域資料夾，可在任何聊天視窗用 @技能名稱 呼叫。
  • 3建立方式簡單：輸入 @ → 選「Create Skill」→ 用自然語言描述需求 → AI 自動生成並全域安裝。
  • 4Demo 1 — PNG 批次轉 WebP：描述需求後，AI 建立「image to WebP」技能；轉換後圖片縮小至原本的 1/10 大小。
  • 5Demo 2 — 呼叫外部 API 生成圖片：透過 fal.ai + Gemini Imagen 2，本機模型負責協調，圖片由雲端 API 實際生成；展示 Skill 整合外部服務的能力。

Skills 的核心優勢

優點說明
執行更快AI 不需每次重新生成腳本
更可靠固定的預先定義指令集，行為一致
省 Token每次任務使用更少 Token
弱模型也能用小模型擅長「照指令執行」；可用強模型建立 Skill、弱模型執行

建立 Skill 時使用較智慧的模型（如 Gemma 4 12B），執行時可換成更輕量的模型，兼顧品質與速度。

注意事項

  • 如在描述 Skill 時直接貼入 API Key，務必使用一次性或已廢棄的金鑰，避免外洩風險。
  • LM Studio Bionic 目前為測試版，功能仍在快速演進，建議追蹤官方更新。

影片說明欄

In this video, I'm going to show you how to build custom Skills using LM Studio Bionic. LM Studio Bionic is a new Agentic AI tool from LM Studio — different from the regular version. Skills are reusable instruction sets (with documents, code, and command prompts) that AI agents can follow to automate tasks on your computer. Two demos covered: 1. Image → WebP batch converter (local skill, ~1/10 file size) 2. Text-to-image via fal.ai + Gemini Imagen 2 (external API integration) Skills are stored globally and accessible in any chat window. You can build them with a smart model and run them with a lighter one. Subscribe for more AI tutorials and use cases!
