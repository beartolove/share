重點摘要

Agentic OS 的想像是：人描述目標，讓 Agent 協調工具、環境與修復流程；真正的課題則是權限、可控性與信任。

  1. 從操作軟體到交付目標：不再先選 App 與研究選單，而是交代想完成的事。
  2. 減少「怎麼做」的負擔：Agent 可串接讀檔、改程式碼、執行、安裝相依套件與排查日誌等步驟。
  3. 作業系統層的轉向：影片以 Omarchy／Agentic OS 的方向，討論把 Agent 工作流整合到開發環境。
  4. 新的介面是意圖與權限：使用者仍需界定目標、可動用資源及何時需要人工確認。
  5. 導入先求可控：企業應由低風險、可回復、可稽核任務開始，保留人工核准關卡。
