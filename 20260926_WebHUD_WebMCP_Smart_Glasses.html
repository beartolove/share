我參加 WebMCP 比賽：開源 WebHUD 智慧眼鏡系統

WebHUD 的提案不是再做一套被硬體品牌綁定的眼鏡 AI，而是將眼鏡化為顯示器、將介面做成網頁，讓你原本使用的 AI Agent 依自身記憶、連接器與資料來源提供服務。

重點摘要

  • WebMCP：讓網站把能力以工具形式提供給 AI Agent，降低只能看畫面、猜 DOM、逐步點擊的操作成本。
  • WebHUD：眼鏡是顯示器、介面是響應式網頁、核心是使用者既有的 WebMCP Agent。
  • 智慧響應：同一份語意資料在桌面可呈現表格，在鏡片則轉為易讀、可滑動的卡片。
  • 互動：語音之外，可用手勢或藍牙指環快速切換資訊與操作。
  • 工具註冊：依目前情境動態提供可用工具，減少無關工具與 Agent 誤操作。

一句話總結

Agent 決定「要做什麼、為什麼」，WebHUD 依裝置與情境決定「怎麼呈現」；如此可把同一套個人 AI 助理帶到桌面、手機與眼鏡顯示器。

怎麼運作

Agent 層

使用既有 Agent 的連接器、記憶、偏好與資料來源，決定任務與內容。

WebMCP 工具層

網頁以 document.modelContext.registerTool 等方式註冊能力，並視情境調整工具可用性。

呈現層

同一個意圖可轉成桌面表格、郵件卡片、閱讀器或眼鏡鏡片的精簡視圖。

Demo 與技術重點

  • 影片用最新電子郵件、行事曆與附件展示 HUD 卡片；鏡片模式一次聚焦一張可滑動資訊卡。
  • WebHUD repo 提供郵件、行事曆、檔案、選擇、面板與地圖路線等工具面。
  • 專案以 MIT 授權開源，並提供公開 demo；WebMCP 測試需留意 Chrome 旗標與 Agent 相容性。

限制與安全提醒

  • WebMCP、瀏覽器與智慧眼鏡支援仍在快速演進，實際可用性需依裝置與 Agent 環境測試。
  • 電子郵件、行事曆與雲端檔案可能含個資；應最小化顯示、避免在公共場域展示敏感資訊。
  • 工具暴露不等於可任意執行；重要動作仍應設計確認、最小權限與可撤銷流程。

提醒：此頁依影片與專案文件整理，並非特定眼鏡硬體、瀏覽器或 Agent 的相容性保證。
