重點摘要

一句話總結

Pi Durable 是 Pi 團隊推出的實驗性 Agent Harness：把會話、任務、工具呼叫與應用狀態先持久化，再執行與呈現，讓長時間 Agent 在崩潰、重啟或重新部署後，能從可追溯的檢查點繼續運作。

八類核心能力

  1. 開啟與恢復：以 SQLite、JSONL 或其他存儲保存會話紀錄與任務進度。
  2. 會話與分叉：從任一紀錄點分叉，不必複製完整歷史資料。
  3. 提交與等待：支援排隊、插話轉向、拒絕提交與僅寫入事件。
  4. 會話級設定：指定模型、思考強度、工具、指令與工作目錄。
  5. 擴充機制：加入工具、system prompt 片段與 hooks。
  6. 應用狀態與 checkpoint：將待辦、計畫、工單等狀態與會話一起持久化。
  7. 事件訂閱：將已提交的狀態變化推送到前端或其他客戶端。
  8. 存儲與執行環境：可抽換存儲與工具實際執行的位置。

關鍵觀察

  • 可恢復不等於絕不重複執行。具副作用的工具必須設計重試、冪等與確認機制。
  • 每一步先寫入存儲，才能把分叉、多人協作、Subagent 與運行中更新建立在同一個可信前提上。
  • 多 Agent 系統的關鍵不只在模型，而在狀態、權限、可觀測性與驗收邊界。

實作提醒

  • 先定義外部操作的重試與去重策略，再把它交給背景 Agent。
  • 先建立狀態、驗收與權限邊界，再擴展到多人協作或 Subagent。
  • 官方範例與安裝方式可能更新，實作前請以官方技術資料為準。
