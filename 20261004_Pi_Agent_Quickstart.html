7 分鐘學會使用 Pi：目前最好的 Agent（之一）

Pi 是可自選模型供應商、可檢視用量與對話資料、也能用外掛擴充的開源 Agent Harness。影片示範從安裝、登入供應商到模型與思考深度的日常操作。

重點摘要

一句話總結

Pi 將 Agent Harness 與模型供應商分離：你可依任務、成本與偏好調整模型，同時保留用量、快取與對話資料的可觀測性，並以外掛持續擴充。

為什麼影片作者改用 Pi

  • 模型選擇更開放，可接多家模型供應商。
  • 過程更可見：可查看 token、快取率與價格，對話資訊可保存在本地檔案。
  • 功能更可擴充：可自行或使用社群外掛增加能力。

快速上手流程

  1. 依官方網站方式安裝；影片以 macOS 的 Homebrew 為例。
  2. 以 /login 加入模型供應商，依支援情況使用帳號登入或 API key。
  3. 用 model 檢視與切換模型。
  4. 以 /scoped-models 標記常用模型，降低切換成本。
  5. 以 Ctrl+P 快速切換模型；Shift+Tab 調整思考深度。

注意事項

  • 登入與 API key 的可用性取決於供應商、帳戶方案與規範。
  • 版本、外掛與快捷鍵可能更新；正式導入前請以官方技術資料為準。
  • 企業使用仍應評估 API key 管理、資料流向、成本與權限控管。
