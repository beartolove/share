EmbeddingGemma 2：一個模型理解多種資料

文字、圖片、聲音、影片，都能放進同一個向量空間搜尋。

重點摘要

  • 用共同向量空間理解文字、圖片、音訊與影片，支援跨模態檢索。
  • 依需求載入模組，探索筆電與端側裝置上的本機搜尋。
  • 768 維向量可縮減；256 維的品質與成本取捨仍需依資料驗證。
  • 附件所述小型測試呈現良好效果，但不能直接外推企業環境。
  • 結合生成模型，有機會形成多模態 RAG 與 Agent 的本機檢索層。

本頁依熊熊提供的兩支影片整合筆記與附件整理。模型規格、示範能力及測試數字為附件轉述，未於本次重新實測或獨立查證；小型乾淨資料集的結果不代表企業資料效能保證。

完整內容

  1. EmbeddingGemma 2 是 Google 推出的輕量級開放式多模態 Embedding 模型

    • 可同時處理文字、圖片、音訊與影片。
    • 核心特色是不同資料型態可以放進同一個向量空間。

  2. 最大突破是「跨模態搜尋」

    • 可做到文字找圖片、文字找音訊、文字找影片、音訊找圖片、影片找圖片。
    • 不同媒體只要語意相近，就會被映射到彼此接近的向量位置。

  3. 模型最高約 7.4 億參數，採模組化設計

    • 約 270M 文字模型。
    • 約 170M 視覺 Encoder。
    • 約 300M 音訊 Encoder。
    • 可依需求只載入需要的模組。

  4. 輸出為 768 維向量，並支援降維

    • 可使用 768、512、256、128 維。
    • 採 Matryoshka Representation Learning，可在降低維度後保留部分語意資訊。

  5. 256 維在實測中呈現不錯的品質與成本平衡

    • 256 維的 Top-8 Precision 仍約 95%。
    • 儲存空間約為 768 維的 1/3。
    • 但此結果僅來自小型測試，實際仍需自行驗證。

  6. 可在一般 8GB GPU 筆電執行

    • RTX 4060 8GB 筆電實測：
      • 文字：約 351 MB VRAM
      • 文字＋圖片：約 899 MB
      • 文字＋音訊：約 1,163 MB
      • 完整模型：約 1,510 MB
    • 完整模型約只占 1.5GB VRAM。

  7. 跨模態搜尋的小型實測效果佳

    • 圖片 Top-1：10/10 正確。
    • 圖片 Top-8 Precision：約 95%。
    • 文字→音訊：10/10。
    • 音訊→圖片：20/20。
    • 文字→影片：10/10。
    • 影片→圖片：10/10。

  8. 可以完全在本機執行，資料不必離開設備

    • 不一定需要外部 API。
    • 可以 Offline。
    • 可在手機、筆電、Edge Device 上進行 Embedding 與搜尋。
    • 對隱私、機敏資料與企業內部資料特別有價值。

  9. 可進一步作為多模態 RAG 與 Agent 的基礎

    • 可搜尋的不再只有文字文件。
    • 還可以納入圖片、會議錄音、影片、系統架構圖、現場照片等資料。
    • 架構可形成： 企業資料 → EmbeddingGemma 2 → Vector Search → RAG → LLM / Agent

  10. 真正價值不是單一 Benchmark，而是把企業多媒體知識放進同一個檢索層

    • 過去 RAG 多半是「找文字」。
    • 未來可朝向「搜尋整個企業的多媒體知識」。
    • 但目前公開實測仍屬小型、乾淨資料，正式導入前仍需用自己的企業資料做 Benchmark。
