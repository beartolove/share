Claude更新系列：2026年10-11月

成品層 × 連接層：從成果製作到工具整合。

重點摘要

一句話看懂：這兩個月 Claude 長出了兩層新能力。

  • 成品層：直接做出文件、白板、試算表、儀表板、動畫，還能裝成桌面 App，跟團隊一起改。
  • 連接層：接上你每天用的工具，而且接得越多，也不會把 Claude 的「工作記憶」塞爆。

Claude更新系列：2026年10-11月

一句話看懂：這兩個月 Claude 長出了兩層新能力。

  • 成品層：直接做出文件、白板、試算表、儀表板、動畫，還能裝成桌面 App，跟團隊一起改。
  • 連接層：接上你每天用的工具，而且接得越多，也不會把 Claude 的「工作記憶」塞爆。

先懂一個詞：Context（上下文）

閱讀本文前，先記住這個詞，後面會一直出現。

  • 是什麼：Claude 在一段對話裡的「工作記憶」，你的指令、它讀過的資料、工具說明全都放在這裡。
  • 為什麼重要：塞得越滿，每一輪對話越貴、越慢，表現也會變差。
  • 跟本文的關係：第二部分「連接層」的三項更新，都是在解決「context 被塞滿」這件事。

第一部分：成品層（Artifacts）

1. Artifacts（成品）：所有新功能的共同底座

重點名詞 淺白說明
Artifact Claude 做給你、你會拿去給別人看的東西，例如文件、簡報、表格、白板
分享連結 做好的成品就是一個網頁連結，預設只有你看得到
版本 每次修改都是同一個連結的新版本，不用再互傳「最終版_v3」
  • 用途：以前跟 AI 聊完，要自己複製貼上到 Word、Excel 再傳給同事。現在 Claude 做出來的東西，就是大家要一起用的東西。
  • 目前的類型：Docs（文件）、Slides（簡報）、Design（設計）、Sheets（試算表）、Whiteboards（白板）、Data（儀表板）、Motion（動畫）
  • 簡例：請 Claude「把這週業績整理成一份可以分享的週報」，它做好後按 Share 把連結貼到群組。同事可以直接在頁面上留言，也可以標記 Claude 請它修改。
  • 注意
    • Docs、Slides、Design 所有方案都能用，包括免費版
    • 其他類型多半要付費方案
    • 成品都能匯出成 Word、PDF、PowerPoint、Excel 等格式
    • 原本的 Claude Design 獨立網站在 12/14 關閉

2. 白板（Whiteboards）｜11/10 推出，beta

重點名詞 淺白說明
Whiteboard 你、同事和 Claude 可以一起動手的白板
框選提問 在白板上框起一塊，Claude 只針對那一塊回答
Send to 把整張白板送到 Miro、Lucid 等白板工具繼續用
  • 用途：把腦中一團亂的計畫講給 Claude 聽，它會排成有時間軸、負責人、截止日的白板。誰在等誰，一眼就看得出來。
  • 簡例：你口述「12/18 辦發表會，邀請函 11 月底要發，主視覺要等樣品照，樣品 12 月初才到」。白板排好之後框起這一段問「排得出來嗎？」，它會指出邀請函在截止日前根本做不出來。
  • 常見三種用法
    • 說明：畫出流程或系統怎麼運作
    • 決定：把幾個選項並排比較
    • 產出：把白板直接轉成計畫文件、簡報或進度表
  • 注意
    • 所有付費方案都能用，網頁、桌面、手機都有
    • Enterprise 方案要請管理員到 Organization settings → Artifacts 開啟

3. 試算表（Sheets）｜11/10 推出，beta

重點名詞 淺白說明
Sheets Claude 版的輕量 Excel
變更標示 Claude 改過的儲存格會特別標出來
  • 用途：一句話就做出有分頁、公式、下拉選單的表；不會寫公式也沒關係，用說的就好。
  • 簡例：「做一個活動追蹤表，要有負責人、日期和狀態欄位。」白板排好的任務可以直接接到這張表，每週更新進度。
  • 注意：每份上限 10 萬格，沒有樞紐分析表這類進階功能；需要完整功能就匯出成 Excel。

4. Claude Data（原 Dashboards）｜10/8 推出 beta，11/10 正式上線並改名

重點名詞 淺白說明
儀表板 用圖表即時呈現數字的頁面
資料連接器 讓 Claude 讀取公司資料庫或 CRM 的連線（例如 BigQuery、Snowflake、Salesforce）
  • 用途：老闆問一個數字問題，不用再開單等三天。直接問 Claude，它會查資料、做好圖表，之後也會隨資料自動更新。
  • 簡例：「比較這週和上個月的註冊人數。」想確認數字對不對，點一下數字就能看到背後的查詢語法。
  • 注意：要先接好資料連接器才能用；它定位在「快速探索」，深入分析可以送到 Tableau、Mixpanel 等專業工具。

5. Motion（動畫）｜10/8 推出，beta

重點名詞 淺白說明
Motion 用程式碼讓文字、圖表動起來的短動畫
/motion 在對話框輸入這個指令就能開始做
  • 用途：把報告、圖表變成 30 秒的說明短片，在全員大會上播放。
  • 簡例：官方示範是共享單車的山坡站每天 8:15 就沒車了。先做成儀表板，再在圖表上留言「做成全員大會用的動畫」。
  • 注意：
    • 它不是影片生成模型，畫面裡不會有 AI 生成的人物，數字都是真實資料，任何一個字都改得到
    • 目前限 Team／Enterprise 方案

6. Artifacts 變 App｜約 11/25，beta

重點名詞 淺白說明
Install as app 把做好的成品安裝成電腦上的獨立應用程式
選單列／系統匣 Mac 螢幕上方、Windows 右下角的小圖示
  • 用途：不寫程式、不用申請開發者帳號，就能有自己的桌面小工具，例如待辦清單、系統監控、圖片編輯器。
  • 簡例：請 Claude 做一個「發票整理器」，然後選 Share → Install as app。之後只要把發票丟進指定資料夾，它就會自動整理。
  • 能力：
    • 最多 100MB 資料儲存
    • 能使用 Claude 和你接好的連接器
    • 可以發通知、設快捷鍵
  • 注意：
    • 能存取整台電腦的權限，只能給自己做的 App
    • Anthropic 不審查這些 App，來路不明的不要給權限

第二部分：連接層

7. 互動式連接器（Interactive Connectors）｜11/10 推出

重點名詞 淺白說明
連接器（Connector） 讓 Claude 接上外部工具的線
互動式 工具不再只是一張小預覽，而是整個在對話旁邊打開，可以直接操作
  • 用途：不用切換視窗，在 Claude 旁邊就能直接用 Notion、Adobe、Box、Canva、Asana 等工具。
  • 簡例：丟一張照片請 Claude「加上網點效果」，Adobe 的編輯面板就在旁邊打開，還能自己調強度。
  • 注意：Claude 做的修改要你核准才會生效。

8. MCP 2.0｜一系列升級，10/23 起陸續上線

重點名詞 淺白說明
MCP 讓 AI 接工具的共通規格。可以想成一個鑰匙圈，每把鑰匙是一個工具功能
Skills（技能） 教 Claude「怎麼做某件事」的說明書，需要時才翻開
Skills over MCP MCP 伺服器自己附上說明書，教 Claude 怎麼用這套工具
Tasks 很久的工作丟到背景跑，完成再通知你，像拿號碼牌
Elicitation 做危險動作之前，先停下來請你確認
  • 用途：以前接了工具，Claude 只拿到一串鑰匙，要自己猜怎麼用。現在說明書一起附上，而且只在需要時才讀，不會塞滿 context。
  • 簡例
    • 接上 GitHub 之後輸入 /github，會出現 GitHub 官方附的一串技能（寫 issue、準備發版等）
    • 叫它刪掉某個 repo，它會先要你輸入 repo 名稱才動手
  • 時間點：
    • Tasks 和 Elicitation 在 10/23 先於 Claude Code 終端機上線
    • Skills over MCP 是 MCP 正式規格的擴充，各工具陸續支援中
    • 「檔案直接上傳給伺服器、不經過對話」這項還沒上線

9. Code Mode｜11/12 推出，實驗功能

重點名詞 淺白說明
Tool call（工具呼叫） Claude 每讀一個檔、跑一個指令，就是一次工具呼叫
Code Mode Claude 先寫一小段程式，在程式裡把工具都呼叫完、結果篩好，只把答案帶回來
  • 用途：工作量大、要動用很多工具時，可以省下大量 context。
  • 簡例：從 200 個 issue 挑出 5 個跟登入有關的。
    • 以前：200 個 issue 的內容全部塞進對話
    • 現在：在程式裡篩完，只帶回那 5 個
    • 比喻：以前實習生每拿一個資料夾就從頭念一遍給你聽；現在他自己翻完，只遞給你一張便條
  • 實測重點
    • 一開場 context 就少了大約 2 萬 token
    • 但換算成實際費用，多數只省 1～2 成
    • 有些小任務反而更慢
  • 注意：
    • 只能在 Claude Code 終端機用，版本要 2.1.323 以上
    • 要設定環境變數 CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 才會開啟
    • 這是實驗功能，隨時可能改變

連接層小結：第 8 項與第 9 項在解決同一個問題，就是工具越多，context 越滿。

  • MCP 2.0 從工具那一端下手：說明書需要時才讀
  • Code Mode 從 Claude 這一端下手：在程式裡篩完再回報
