一句話總結：影片提供從基礎程式能力、模型 API 到 Agent 專案實作的學習路線，重點在以可完成的小作品累積能力。

## 核心重點
1. 先建立程式、資料處理與 API 的基本功，再把模型能力接入實際流程。
2. Agent 不只是對話模型；還需要工具呼叫、狀態、記憶、錯誤處理與驗收機制。
3. 選擇小而具體的題目，讓輸入、輸出、成功條件都可測試。
4. 專案成果要保留設計取捨、測試方式與失敗案例，才能真正累積工程能力。

## 學習提醒
- 不要急著追逐框架；先能說清楚問題、資料、流程與驗收標準。
