一句話總結：影片示範用 Round Table 協調多個 Hermes AI，同時分工處理任務，並以清楚的角色與交接降低多人協作的混亂。

## 核心重點
1. 多 Agent 的價值不在同時開更多視窗，而在工作切分、責任邊界與交接格式。
2. Round Table 用共用工作區讓 Agent 能看到任務狀態與相互產出，避免重複做事。
3. 適合並行的工作應彼此獨立，例如研究、比對、撰寫與驗證；高度相依工作仍要有順序。
4. 每位 Agent 都應有清楚的輸入、可驗收輸出與停止條件。
5. 人仍要負責設定優先順序、核對品質、處理衝突與決定是否採用結果。

## 導入提醒
- 從兩到三個角色的短流程開始，先建立可追蹤的任務格式，再擴大並行數量。
- 不要讓多個 Agent 同時修改同一個關鍵產物；應指定單一整合者與版本驗證步驟。
